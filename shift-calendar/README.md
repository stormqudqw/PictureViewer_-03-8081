# 🗓️ Календарь смен — учёт дохода

Универсальное веб-приложение для учёта рабочих смен и дохода. Подходит для любой
профессии со сменным графиком: вы создаёте **шаблоны смен**, проставляете их по
дням календаря, а приложение считает заработок и собирает статистику. Календарь и
статистику можно **экспортировать в Excel** (или CSV).

Приложение полностью клиентское — никакого сервера и установки не требуется.
Данные хранятся локально в браузере (`localStorage`).

## Возможности

- **Шаблоны смен** — название, время начала/окончания (в т. ч. ночные смены через
  полночь), перерыв, цвет и тип оплаты:
  - почасовая ставка;
  - фиксированная сумма за смену.
- **Календарь** — месячный вид. Выберите активный шаблон и кликайте по дням, чтобы
  быстро проставить смену. В одном дне может быть несколько смен.
- **Управление днём** — клик по дню без активного шаблона открывает окно, где можно
  добавлять и удалять смены за эту дату.
- **Автоматический расчёт дохода** — по каждой смене, дню и периоду.
- **Статистика** — за месяц / год / всё время: общий доход, отработанные часы,
  число смен, средний доход за смену и разбивка по шаблонам.
- **Экспорт в Excel** (`.xls`, формат SpreadsheetML) с двумя листами:
  *Календарь* (детализация смен) и *Статистика* (сводка). Открывается в Excel,
  LibreOffice Calc и Google Sheets без дополнительных библиотек.
- **Экспорт в CSV** (разделитель `;`, корректно открывается в русской Excel).
- **Настраиваемая валюта** (символ в шапке).

## Запуск

Откройте файл `index.html` в браузере — всё работает локально.

Либо запустите простой статический сервер из папки `shift-calendar`:

```bash
python3 -m http.server 8081
# затем откройте http://localhost:8081
```

## Как пользоваться

1. В панели **«Шаблоны смен»** при первом запуске уже есть примеры. Добавьте свои
   через **«+ Добавить»** или отредактируйте существующие (значок ✎).
2. Кликните по шаблону — он станет **активным** (кисть). Теперь клики по дням
   календаря мгновенно проставляют эту смену.
3. Сбросьте активный шаблон, чтобы клик по дню открывал окно управления сменами.
4. Следите за заработком в панели **«Статистика»**, переключая период.
5. Нажмите **«⬇ Экспорт в Excel»** или **«⬇ CSV»** — выгрузится текущий период.
