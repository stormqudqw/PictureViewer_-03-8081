# Осколки Эфира (Shards of Ether)

Браузерная Action-RPG по концепту «Осколки Эфира», реализованная на чистом
JavaScript + HTML5 Canvas — без сборки, без зависимостей, с упором на
качественную графику и отличную оптимизацию.

![tech](https://img.shields.io/badge/engine-Canvas2D-7c5cff) ![deps](https://img.shields.io/badge/dependencies-0-5bffb0) ![build](https://img.shields.io/badge/build-none-ffce6b)

## Запуск

ES-модули требуют HTTP (file:// блокируется браузером). Запустите локальный
статический сервер из папки `EtherShards`:

```bash
cd EtherShards
python3 -m http.server 8081
# затем откройте http://localhost:8081/
```

Либо любой статик-хостинг (GitHub Pages, Netlify): корнем сделайте папку
`EtherShards`, и `index.html` подхватится автоматически.

## Управление

| Клавиша | Действие |
| --- | --- |
| `W A S D` | движение |
| `ЛКМ` | удар ближнего боя (качает Меч) |
| `ПКМ` / `Q` | заклинание (основная стихия) |
| `E` | вторая стихия |
| `1 2 3 4` | стихии для **комбо-магии** (две подряд → реакция) |
| `Space` | рывок / уклонение (качает Ловкость) |
| `R` | активная способность (талант) |
| `F` | взаимодействие (алтарь, портал, NPC, эфир) |
| `C` | персонаж · `T` таланты · `M` карта мира · `B` ядра |

## Реализованные механики концепта

- **Три пути развития** — Воин / Маг / Инженер через характеристики и таланты;
  навыки свободно комбинируются.
- **Гибридные классы** — Техномант (Интеллект 20 + Техника 20), Боевой маг,
  Паладин-механик, открываемые вложением в характеристики.
- **Система Эфирных Ядер** — боссы дают Ядра, меняющие способности,
  характеристики и облик (огненный след, щит и т. п.).
- **Развитие через использование** — мастерства меча, уклонения, тайных
  искусств и инженерии растут от применения.
- **Мутации** — нестабильный эфир: принять, подавить или развить (есть
  положительные и отрицательные).
- **Живая репутация** — три фракции (Орден Света, Свободные Кланы, Машинный
  Союз); действия меняют отношение, цены и доступность спутников.
- **Комбо-магия** — лёд+молния = электрошторм, огонь+ветер = смерч и др.
- **Разрушаемое окружение** — разрушаемые объекты, ловушки, зоны урона.
- **5 характеристик** (Сила/Ловкость/Интеллект/Техника/Воля), уровни до 100,
  по 3 очка характеристик и 1 очко таланта за уровень.
- **Древо талантов** — боевая, магическая, инженерная и гибридная ветки.
- **Спутники** — дух-спутник, эволюционирующий с уровнем; фракционные дроны.
- **Эндгейм: Бесконечные Разломы** — этажи с модификаторами (взрывы при
  смерти, двойная магия, запрет лечения и т. д.) и масштабируемой сложностью.

## Оптимизация

- Статический слой каждого острова рендерится один раз в offscreen-canvas и
  выводится одним `drawImage` за кадр.
- Система частиц на типизированных массивах с фиксированным пулом —
  без аллокаций в горячем цикле.
- Аддитивный блендинг и радиальные градиенты для свечения вместо растровых
  ассетов (мгновенная загрузка, ноль сетевых запросов).
- Камера с тряской на основе «травмы», динамическим зумом и сглаживанием.
- Ограниченный `dt`, отбраковка мёртвых сущностей, дешёвое разделение врагов.

## Архитектура

```
EtherShards/
├── index.html          точка входа + разметка HUD/меню
├── styles.css          оформление UI
├── src/
│   ├── engine.js       математика, RNG, ввод, камера, частицы, звук
│   ├── data.js         весь дизайн-контент (таланты, ядра, фракции, враги…)
│   ├── world.js        генерация парящих островов, порталы, объекты
│   ├── entities.js     игрок, враги, боссы, снаряды, спутники
│   ├── systems.js      репутация, разломы, сохранения
│   ├── ui.js           HUD, панели, модальные окна, миникарта
│   └── main.js         игровой цикл, спавн, взаимодействия, рендер
└── test/
    └── smoke.mjs       headless smoke-тест (мок DOM/Canvas) — `node test/smoke.mjs`
```

## Тесты

```bash
node test/smoke.mjs
```

Поднимает игру в Node с мок-DOM/Canvas, прогоняет старт, бой, прокачку,
изучение талантов, выпадение ядра с босса, разлом и round-trip сохранения.
